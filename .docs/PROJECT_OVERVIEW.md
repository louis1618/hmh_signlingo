# 프로젝트 개요 (Project Overview)

본 문서는 **AI 기반 실시간 수어 학습 및 번역 플랫폼 (SignLingo)** 프로젝트의 전체적인 개요, 개발 배경, 문제 정의 및 핵심 가치를 기술합니다.

---

## 1. 프로젝트 정의
**SignLingo**는 사용자의 웹캠 영상을 실시간으로 3D 스켈레톤 및 손 관절 데이터로 추출하고, 이를 딥러닝 AI 모델과 연동하여 실시간 수어 인식 및 번역을 수행하는 인터랙티브 웹 애플리케이션입니다. 동시에 3D 아바타 튜터를 제공하여 사용자가 수어의 입체적인 동선과 디테일한 손 모양을 3D 그래픽 환경에서 직관적으로 따라 하며 배울 수 있는 양방향 학습 플랫폼을 제공합니다.

---

## 2. 개발 배경 및 문제 정의

### 기존 수어 학습 시스템의 한계
* **영상 학습의 2차원적 한계:** 기존의 '동영상 시청 후 따라 하기' 학습 방식은 카메라 각도가 고정되어 있어 손가락의 굽힘 정도나 몸과의 거리 등 입체적인 깊이(Depth) 정보를 파악하기 어렵습니다.
* **단방향성 및 피드백 부재:** 사용자가 동영상을 보며 자신의 동작을 직접 모니터링하기 어렵고, 자신이 행한 동작이 올바른지 실시간으로 평가해주는 피드백 시스템이 결여되어 있습니다.
* **동영상 컨텐츠 제작 및 유지 보수의 높은 비용:** 새로운 단어를 추가하려면 수어 연기자 섭외, 스튜디오 녹화, 영상 편집 등의 막대한 인프라 비용과 시간이 수반됩니다.
* **시간 정렬(Temporal Alignment) 실패:** 사용자마다 수어를 취하는 속도가 달라 기존 단순 픽셀 기반 비교는 높은 오인식률을 초래합니다.

## 3. 핵심 해결 방안 및 가치 제안

### 3D 아바타 튜터링 (Sign Language 3D Tutor)
표준 수어 데이터를 2D 동영상이 아닌 **3D 관절 좌표 시퀀스 데이터**로 변환하여 저장합니다. 이를 기반으로 웹 브라우저 내에서 3D 캐릭터 아바타가 학습자에게 표준 수어를 입체적으로 재생합니다. 사용자는 마우스 인터랙션을 통해 아바타를 360도 회전하거나 줌인/줌아웃하여 모호했던 손동작과 팔꿈치 위치를 정교하게 관찰할 수 있습니다.

### 실시간 온디바이스 트래킹 (On-device Tracking)
브라우저 내에서 MediaPipe 엔진을 통해 디바이스 메인 스레드에 부담을 주지 않고 사용자의 신체와 양손 동작을 정밀 캡처합니다. 이를 통해 특수 센서(Leap Motion, Kinect 등) 없이 일반 웹캠만으로 누구나 손쉽게 시스템을 이용할 수 있도록 접근성을 극대화합니다.

### 딥러닝 기반 실시간 제스처 스포팅 (Continuous Inference)
사용자가 수어 동작을 연속해서 행할 때 이를 정형화된 프레임 블록(`124프레임`) 단위로 캡처하여 균일한 크기(`60프레임`)로 압축, 딥러닝 모델로 실시간 전송합니다. AI가 시간차와 속도 변이를 알아서 정규화하여 학습자가 복잡한 시작/끝 버튼 조작 없이 카메라 앞에서 자유롭게 학습할 수 있는 **Continuous UI**를 구축합니다.

## 4. 핵심 구현 기능 리스트

| 기능 영역 | 구현 완료 기능 | 미구현 / 개선 예정 기능 |
|---|---|---|
| **3D 시연 (Tutor)** | • R3F 및 `@pixiv/three-vrm` 기반 3D 아바타 로딩<br>• 백엔드 `/api/motion/{word}`에서 3D 궤적 데이터를 실시간 로딩하여 아바타를 구동<br>• 마우스 및 터치 제어 360도 뷰어 지원 | • 얼굴 비수지 기호(눈썹, 눈, 입 모양)를 3D 아바타 BlendShape에 실시간 동기화<br>• 상체 Idle 모션과 수어 재생 모션의 유기적 블렌딩 |
| **실시간 인식 (Practice)** | • MediaPipe Pose & Hand 랜드마크 추출<br>• 위상학적 OpenPose Body-25 정형화 매핑 및 목 기준 Torso 정규화<br>• WebSocket을 통한 실시간 PyTorch 추론 및 일치 여부 피드백 | • 연속 인식 시 이전 잔상에 의한 오오염 방지를 위한 버퍼 플러시 로직의 고도화 |
| **연속 번역 (Translator)** | • 슬라이딩 윈도우 기반 실시간 번역 UI 구축<br>• 중복 제거용 임계 쿨다운(1.2초) 제어<br>• 실시간 인식 단어의 누적 리스트업 | • 백엔드 `/api/generate-sentence` API(Gemini 2.5 Flash)를 프론트엔드에 직접 동기화하여 자연스러운 완성 문장 출력 구현 |
| **콘텐츠 관리 (CMS)** | • IndexedDB 기반 로컬 챕터/레슨 추가 및 삭제<br>• 웹캠 기반 커스텀 3D 궤적(Variants) 실시간 캡처 및 DB 저장 스튜디오 | • 저장된 로컬 Variants 데이터를 백엔드로 내보내어 모델 재학습용 데이터셋에 자동 반영하는 Sync 기능 |
| **시스템 페이지** | • 메인 학습 맵(LearningMap) 화면 구성<br>• IndexedDB 데이터 부재 시 백엔드 API로부터 Curriculum 자동 주입 시딩 | • 리더보드(순위) 탭 기능 상용화<br>• 프로필 및 개인 누적 통계 탭 기능 구현 |
